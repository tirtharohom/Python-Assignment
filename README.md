# Student Record and Academic Management System

## Python Unit 2 Project

A console-based Python project demonstrating the practical use and integration of:

- Strings
- Lists
- Tuples
- Sets
- Dictionaries

## Features

1. Add Student
2. Search Student by Roll Number
3. Update Student
4. Delete Student
5. Display All Students
6. Calculate Average Marks
7. Find Highest Scorer
8. List Students by Department
9. Count Students
10. Generate Reports
11. Exit

## Data Structures

| Data Structure | Usage |
|---|---|
| String | Names, departments, addresses and email IDs |
| List | Student records, subjects, marks and attendance |
| Tuple | Roll number, registration number and date of birth |
| Set | Departments, subjects and student clubs |
| Dictionary | Complete student profile |

## Project Files

- `integrated_system.py` - complete working application
- `main.py` - application entry point
- `string_programs.py` - string demonstrations
- `list_programs.py` - list demonstrations
- `tuple_programs.py` - tuple demonstrations
- `set_programs.py` - set demonstrations
- `dictionary_programs.py` - dictionary demonstrations
- `documentation/` - project documentation
- `flowcharts/` - flowchart files
- `screenshots/` - execution screenshots

## How to Run

Install Python 3.

Then open the project folder in a terminal and run:

```bash
python integrated_system.py
```

or:

```bash
python main.py
```

## Validation

The system handles:

- Duplicate roll numbers
- Invalid numeric input
- Invalid marks and attendance
- Empty input
- Invalid menu choices
- Empty student records
- Search/delete of non-existing students

## Testing

The project should be tested using normal, duplicate, invalid, empty and boundary test cases.
